# seminar-material-generator

학회, 기술 컨퍼런스, 사내 세미나 발표를 위한 **16:9 와이드스크린 반응형 프레젠테이션 슬라이드 덱**(`slides.html`)을 생성하는 에이전트 스킬입니다.  
`study-material-generator`의 디자인 토큰과 UI 스타일을 상속받아 시각적 일관성을 완벽히 유지합니다.

---

## 1. 핵심 특징 및 아키텍처 (Key Features)

1. **16:9 반응형 가상 뷰포트**:
   - 어떤 화면 해상도(FHD, 4K, 프로젝터 XGA)에서도 비율 왜곡 없이 화면 중앙에 자동 스케일링(`1920x1080` 기준).
2. **슬라이드-문서 듀얼 모드 (Slide & Docs Dual Mode)**:
   - **`D` 키 (Docs / Handout 모드)**: 파일을 전달받은 독자가 세로로 스크롤하며 슬라이드 화면과 발표자 노트(대본/해설)를 한눈에 기술 문서처럼 편안하게 정독할 수 있는 핸드아웃 뷰 토글.
3. **단일 HTML 파일 자급자족성 (Zero-Dependency Single File)**:
   - 복잡한 빌드 도구 없이 브라우저에서 더블 클릭만으로 즉시 구동.
4. **무대 중심 발표 인터랙션 (Stage-Ready UX)**:
   - **뎁스 앤 블러 슬라이드 전환 애니메이션 (Depth & Frosted Blur Transition)**: 슬라이드 이동 시 현재 슬라이드는 깊이감 있게 축소(`scale(0.85)`)되며 가우시안 블러(`filter: blur(16px)`)와 함께 페이드아웃되고, 대상 슬라이드는 전면으로 확대(`scale(1)`)되며 선명하게 포커싱(`filter: blur(0px)`). 퇴장 잔상(`visibility 0.45s`) 보존 및 `prefers-reduced-motion` 자동 대응.
   - **스마트 하단 가이드 바 마우스 호버 전용 노출**: 슬라이드 몰입도를 위해 평상시(슬라이드 넘김 포함) 화면 하단 밖으로 완벽 숨김되며, 오직 마우스 커서가 화면 맨 아래쪽(하단 90px 이내)으로 접근하거나 포커스될 때만 부드럽게 슬라이드 업되어 노출.
   - **마우스 휠 스크롤 & 모바일 터치 네비게이션 (Wheel & Touch Navigation)**: 마우스 휠 상/하 스크롤로 직관적인 슬라이드 넘김 지원, 관성 스크롤 및 트랙패드 폭주 방지를 위한 $400\text{ms}$ 쿨다운 락(`wheelLock`)과 슬라이드 내부 스크롤 보호 적용, 모바일 좌우 터치 스와이프 지원.
   - **발표자 모드 (`P` 키)**: 듀얼 모니터용 팝업 창 활성화 (현재/다음 슬라이드, 발표자 노트/대본, 발표 경과 시간 타이머 동기화).
   - **오버뷰 그리드 모드 (`O` 또는 `Esc` 키)**: 전체 슬라이드 썸네일 그리드 조망 및 빠른 점프.
   - **단축키 안내 모달 (`?` 또는 `Shift + /`)**: 전체 키보드 단축키 및 휠 제어 치트시트 팝업.
   - **화면 일시 암전 (`B` 키)**: 청중 집중 유도를 위한 블랙아웃.
   - **전체화면 (`F` 키)**, **테마 전환 (`T` 키)**.
5. **고품질 시각 요소 통합**:
   - Mermaid.js 아키텍처 다이어그램 (동적 렌더링, 컨테이너 핏팅 오버플로우 방지, 확대 시 라이트 테마 고대비 캔버스 모달 지원, SVG 다운로드 지원).
   - 패킷 헤더 구조용 반응형 고대비 비트필드 표(`.bitfield-table`).
6. **PDF 인쇄 최적화 (`Ctrl + P`)**:
   - `@page { size: landscape; margin: 0; }` 스타일 적용으로 잘림 없는 16:9 고해상도 PDF 슬라이드 덱 즉시 인쇄.

## 2. 슬라이드 생성 전 필수 인터뷰 체크리스트 (Pre-generation Interview Checklist)
사용자가 명시적으로 정보를 제공하지 않은 경우, 에이전트는 슬라이드 덱 저작에 착수하기 전 반드시 다음 6대 메타데이터를 질문하여 확정해야 합니다:

1. **보안 등급 문구 (`classification`)**:
   - `CONFIDENTIAL` (붉은색 보안 경고 배지), `INTERNAL USE ONLY` (앰버색 사내용 배지), `PUBLIC` (녹색 공개용 배지), 또는 `null`/빈 칸 (미표시).
   - 각 슬라이드 상단 중앙 및 Docs 핸드아웃 모드 헤더에 고정 렌더링됩니다.
2. **발표 행사/세미나 명칭 (`event`)**:
   - 예: 사내 기술 교류회, 춘계 학술대회, Tech Summit, 고객사 아키텍처 워크숍 등. 표지 뱃지 및 슬라이드 컨텍스트로 활용.
3. **발표자 및 소속 정보 (`presenter`)**:
   - 발표자 성명, 역할/직함, 소속 조직/연구소, 발표 일시.
4. **발표 목표 시간 및 슬라이드 분량 (`duration`)**:
   - 15분 (라이트닝 톡, 8~10장) / 25분 (일반 세션, 14~16장) / 45분 (키노트/심층 세미나, 20~25장). 슬라이드당 1.5분 기준으로 분량과 스피치 대본의 호흡을 결정.
5. **대상 청중의 전문성 레벨 (`audience`)**:
   - 심층 기술 엔지니어 (비트필드, 와이어 프레임, 커널 IPC 등 깊이 있는 엔지니어링 집중)
   - 경영진 및 의사결정자 (시스템 아키텍처 트레이드오프, 비용, 비즈니스 연속성 집중)
   - 범용 개발자 (개념 설명, 사용 패턴, 프레임워크 비교 중심)
6. **핵심 메시지 (Key Takeaway)**:
   - 청중이 세미나 종료 후 반드시 기억해야 할 결론 One-liner.

## 3. 슬라이드 저작 규칙 (Authoring Rules)

- **슬라이드 분량 및 시간 배분**:
  - 사용자 인터뷰에서 확정된 발표 시간에 맞춰 슬라이드 수 조절 (슬라이드당 1~2분 소요).
  - 전체 슬라이드 흐름: `Cover` ➔ `Agenda` ➔ `핵심 챕터별 논점(Split/Stacked/Diagram)` ➔ `비교 매트릭스(Comparison)` ➔ `Takeaway` ➔ `Q&A`.
- **전문성 타이포그래피 및 이모지(Emoji) 엄격 배제**:
  - 본문 텍스트, 슬라이드 제목, 불릿, 표, 다이어그램 등 전반에서 이모지(Emoji)를 일체 사용하지 않습니다.
  - 학술 및 엔지니어링 세미나 품격에 맞게 정갈한 CSS 뱃지, 코드 블록, 볼드 타이포그래피로 구조화합니다.
- **불릿 텍스트 간결화 (Scannability)**:
  - 슬라이드당 불릿은 **3~4개 이하**로 제한하며, 각 불릿은 명사형 종결 또는 굵은 키워드로 시작.
  - 슬라이드 화면에 긴 설명 문장을 절대 직접 넣지 말 것 (설명은 모두 발표자 노트로 이동).
- **발표자 노트 (Speaker Notes) 필수화 (CRITICAL)**:
  - 모든 슬라이드의 `notes` 필드에 **실제 청중에게 말하는 구어체 스피치 스크립트**, **예상 소요 시간**, **청중 강조 포인트**, **질의응답 방어 논리**를 상세히 작성.
- **다이어그램 배치 다형성 (`split` 좌우 vs `stacked` 상하)**:
  - **가로형 다이어그램**(`sequenceDiagram`, `graph LR`), 와이드 비교 표: `"layout": "stacked"`를 사용하여 상단 2~3줄 요약 + 하단 와이드 캔버스로 글씨 왜곡을 방지.
  - **세로형 다이어그램**(`graph TD`), 비트필드 표: `"layout": "split"`을 사용하여 좌측 텍스트 + 우측 캔버스로 안정적인 균형을 확보.
  - 미지정 시 템플릿의 지능형 엔진이 시퀀스/가로형 다이어그램을 감지하여 자동으로 `stacked`로 전환.
- **기술 핸드아웃 문서 뷰 (Docs Mode - `D` 키)**:
  - 단순 슬라이드 캡처가 아닌, **목차(TOC) 트리, 서술형 문단, 대형 다이어그램 뷰, 상세 엔지니어링 해설 블록**으로 구성된 엔지니어링 백서 형태로 독자가 스크롤하며 편안하게 정독 가능.
  - 상단 툴바에 테마 전환 버튼(`T` 키) 및 보안 등급 뱃지 상시 노출.
- **뎁스 앤 블러(Depth & Frosted Blur) 슬라이드 전환 및 스마트 인터랙션**:
  - 슬라이드 전환 시 깊이감 있는 줌스케일(`scale(0.85)`), 퇴장 잔상 보존(`visibility 0.45s`), 프로스티드 가우시안 블러(`filter: blur(16px)`)가 조화된 모던 테크 컨퍼런스 트랜지션이 기본 제공됩니다.
  - **스마트 하단 가이드 바 마우스 호버 전용 노출**: 슬라이드 감상 및 발표 몰입도를 위해 평상시(슬라이드 넘김 포함)에는 하단 밖으로 완벽 숨김되며, 오직 마우스 커서가 화면 맨 아래쪽(하단 90px)으로 내려가거나 포커스될 때만 부드럽게 슬라이드 업됩니다.
  - 마우스 휠 스크롤 및 모바일 좌우 터치 스와이프로 직관적인 페이지 넘김이 가능하며, 관성 휠 폭주 방지(400ms 쿨다운 락)와 모달/내부 스크롤 보호가 적용되어 있습니다.
- **PDF 인쇄 최적화 (`Ctrl + P`)**:
  - `@page { size: landscape; margin: 0; }` 스타일을 통해 1페이지당 정확히 1슬라이드가 100% 핏되어 잘림 없이 깨끗하게 출력.

## 4. 워크플로우 (Execution Workflow)

1. **템플릿 로드**:
   - `skills/seminar-material-generator/assets/template.html`을 읽습니다.
2. **슬라이드 데이터 구성**:
   - 주제 및 발표 대상(학회, 사내 세미나 등)에 맞춰 `slides-data` JSON 구조를 조립합니다.
3. **HTML 파일 생성**:
   - `<script type="application/json" id="slides-data">` 태그 내부에 데이터를 주입하여 `output/<topic>/slides.html`로 저장합니다.
4. **검증 실행**:
   ```bash
   python skills/seminar-material-generator/scripts/validate-slides.py output/<topic>/slides.html
   ```
5. **오프라인 번들 생성 (필요 시)**:
   ```bash
   python skills/seminar-material-generator/scripts/bundle-offline.py output/<topic>/slides.html
   ```
